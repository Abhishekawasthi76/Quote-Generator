# 💬 Quote Generator

A simple and responsive **Quote Generator Web App** built using **HTML, CSS, and JavaScript**. The application uses an API to fetch and display random quotes along with their authors.

## 🚀 Features

* 💬 Generate random quotes
* ✍️ Display quote author
* 🔄 Fetch new quotes dynamically
* 🌐 API integration
* ⚡ Uses JavaScript Fetch API
* 📱 Responsive design
* 🎨 Simple and clean user interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and DOM manipulation
* **Fetch API** – Fetching quote data from the API

## 🔗 API Used

This project uses an external **Quotes API** to fetch random quotes dynamically.

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Quote-Generator.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Click the **Generate Quote** button to get a new quote.
